 啵啵奶茶工坊

一个模拟手作奶茶的网页小应用，基于原生 HTML / CSS / JavaScript 开发，打开浏览器即可制作属于你的虚拟奶茶。

✨ 项目简介

这是一个轻松解压的“奶茶制作模拟器”。你可以选择茶底、糖度、冰块和配料，自由搭配出一杯奶茶，并查看它的“颜值”和“美味”评分。页面还设计了社区动态和分享功能，让制作过程更有趣。

🎮 主要功能

- **自由调配**：支持选择茶底（如红茶、绿茶）、糖度（七分糖、半糖等）、冰块（正常冰、少冰等）以及配料（珍珠、椰果等）。
- **实时反馈**：根据你的选择，实时生成奶茶的“颜值”和“美味”评分。
- **奶茶预览**：页面中央会显示当前搭配的奶茶杯子样式。
- **分享文案**：一键生成奶茶的分享文案，方便发朋友圈。
- **社区动态**：内置示例奶茶作品和社区卡片，支持点赞和发布。
- **本地存储**：使用 `localStorage` 保存社区内容与个人设置。

 🛠️ 技术栈

- HTML5
- CSS3（Flexbox / Grid、CSS 变量、渐变背景）
- 原生 JavaScript（DOM 操作、事件处理、localStorage）

🚀 如何运行

1. 下载本仓库中的 `奶茶工作坊.html` 文件。
2. 用浏览器（Chrome / Edge / Safari）直接双击打开即可。
3. 推荐使用 VS Code 的 Live Server 插件运行，改代码后浏览器会自动刷新。

📱 使用说明

1. 在“工作台”区域，点击各个选项按钮，选择你想要的茶底、糖度、冰块和配料。
2. 页面会自动更新奶茶的预览图、颜值和美味值。
3. 点击“再来一杯”可以清空当前选择，重新调配。
4. 点击“分享文案”可一键复制奶茶的推荐文案。
5. 在“社区”区域可以看到其他人的作品，也可以点赞和发布自己的奶茶。
